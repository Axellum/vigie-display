The world's hazards, on a screen by the door.

Vigie display is open-source firmware for ESP32-P4 touch screens. It shows the earthquakes, tsunamis, cyclones, floods, wildfires and solar storms happening now, how far they are from the places you watch, and their weather. No cloud account, no Home Assistant: the screen asks a small API for one frame a minute.

Install it Source code

M5Stack Tab5, 1280×720. Rendered from the firmware itself, with live data, by the project's CI.

What the screen shows

One page, readable from across the room, repainted every second and refreshed every minute.

World map

Every active hazard, coloured by severity, and the zones you watch. The most severe ones are drawn on top.

The five most severe alerts

Type, magnitude, source title, distance and direction from the active zone, and how long ago it started.

Weather of the zone

Now, wind and gusts, humidity, rain in the next hour, air quality, waves on the coast, five days ahead. Touch it for the next zone.

Honest about what it knows

A value the API does not know is left out, never shown as zero. When the API stops answering, the screen says how old its data is.

Vigie gathers public data for information. It does not replace official warnings: follow the instructions of your authorities.

How it works

Two open-source parts. The screen never talks to the data sources: they are many, change format, and some answer with megabytes of JSON.

Public sources

USGS, EMSC, GDACS, NOAA, NASA FIRMS, Open-Meteo, MET Norway and official warning services.

→

vigie-api

Merges and deduplicates them, computes distances, serves a text frame of a few kilobytes with a CRC. Public instance, or your own.

→

vigie-display

ESPHome + LVGL on the ESP32-P4: fetches the frame every minute, checks it, decodes it without allocating memory, paints the screen.

The same data on the web: vigie.auxfilsdesidees.fr.

Boards

Two ESP32-P4 screens with an ESP32-C6 for Wi-Fi. Nothing to solder: USB-C for power and the first flash, Wi-Fi for the rest.

Waveshare ESP32-P4 7B Tested

7" IPS, 1024×600. The reference layout. vigie_board: waveshare-7b

M5Stack Tab5 Runs

5" IPS, 1280×720, the same layout at 120 %. ST7123, ST7121 and ILI9881C revisions; runs on an ST7121. vigie_board: tab5

English and French screen texts. Details, pins and known traps: hardware.

Install

You build the firmware with ESPHome, then flash it over USB once. About 30 minutes, most of it the first build. The installation guide has every step and what to do when one fails.

  1. Get ESPHome and the code

    Python 3.11 or newer, ESPHome 2026.9.1 or newer.

    python -m venv .venv
.venv/bin/pip install "esphome>=2026.9.1"
git clone https://github.com/Axellum/vigie-display.git
cd vigie-display

  2. Create your signing key

    The screen only accepts updates signed with it. Keep a copy somewhere safe.

    openssl genrsa -out vigie_signing_key.pem 3072

  3. Build and flash over USB

    Plug the board in, then pick it:

    esphome -s vigie_board tab5 \
  -s vigie_api_url https://vigie.auxfilsdesidees.fr \
  -s vigie_signing_key vigie_signing_key.pem run vigie.yaml
    esphome -s vigie_board waveshare-7b \
  -s vigie_api_url https://vigie.auxfilsdesidees.fr \
  -s vigie_signing_key vigie_signing_key.pem run vigie.yaml

    French screen: add -s vigie_language fr. A Tab5 with an ST7121: -s board_tab5_panel M5STACK-TAB5-ST7121.

  4. Give it your Wi-Fi

    Over USB with ESPHome Web (Improv, Configure Wi-Fi), or join the Vigie setup access point it opens from a phone. Within a minute the status bar reads Up to date.
